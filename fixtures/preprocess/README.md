# Native preprocessing fixtures

These small JPEGs test the bounded F01/F02 API without a dataset, Python runtime,
or checked-in full-size RGB tensors. Run `preprocess_tests fixtures/preprocess`.
The native executable compares repeated native results and checks identity-resize
normalization against the decoded uint8 bytes; these fixtures do not independently
establish decoder equivalence with training. Real-frame independent references
are generated by `training/t01/t01_preprocess_ref.py`.

`generate.py` produced these files offline with Pillow 12.2.0 (`jpg` API 6.2),
quality 95, no optimization. The RGB source is defined exactly by coordinates:
`R=160+(3x+y)%64`, `G=64+(x+2y)%64`, `B=8+(2x+3y)%32`.
`baseline.jpg` is 35x27 to exercise odd subsampled boundaries; `alternate.jpg`
is 48x32 to exercise buffer reuse across dimensions. Both are baseline 4:2:0.
The remaining 35x27 files exercise explicit rejection of unsupported source
contracts: grayscale, CMYK, progressive 4:2:0 and baseline 4:4:4.
